## 检查重点

只检查以下**隐性合规问题**，不重复规则已检查的内容：

### 1. 暗示性绝对化
- 虽然没用"最""第一"等词，但暗示了绝对领先地位
- **示例问题**：
  - "无人能及的性能" ← 暗示最强
  - "行业天花板" ← 暗示第一
  - "别无他选" ← 暗示唯一
  - 判断：error，变相绝对化表述

### 2. 暗示性对比
- 没有直接提及竞品，但暗示优于其他品牌
- **示例问题**：
  - "告别卡顿和发热问题" ← 暗示其他品牌有这些问题
  - "真正的轻薄本" ← 暗示其他不是"真正"的
  - "不像别的笔记本那样..." ← 隐性对比
  - 判断：warn，暗示性对比

### 3. 变相承诺
- 虽然没用"保证""一定"，但暗示了确定的结果
- **示例问题**：
  - "让你的工作效率翻倍" ← 无法保证的效果
  - "再也不用担心续航" ← 变相承诺
  - "解决所有办公需求" ← 过于绝对
  - 判断：error，变相承诺效果

### 4. 夸大效果
- 将有限的功能夸大为万能解决方案
- **示例问题**：
  - "瞬间完成渲染" ← 夸大速度
  - "毫无延迟" ← 过于绝对
  - "完美兼容" ← 夸大兼容性
  - 判断：warn，夸大效果

### 5. 制造焦虑或紧迫感
- 虚构库存紧张、限时优惠（无事实依据时）
- **示例问题**：
  - "库存告急" ← 无依据
  - "错过再等一年" ← 制造焦虑
  - "仅限今天" ← 无依据的限时
  - 判断：error，制造虚假紧迫感

### 6. 暗示个人体验（平台不允许时）
- 虽然没用"我用了"，但暗示了个人使用经历
- **示例问题**：
  - "用了一周，续航依然坚挺" ← 暗示个人体验
  - "实测非常流畅" ← 暗示个人测试
  - 判断：error（小红书等平台明确禁止伪造体验）

### 7. 价格相关问题
- 提及价格、优惠、补贴时，检查是否有事实依据
- **示例问题**：
  - 稿件提到"优惠XXX元"，但事实清单中无此信息
  - 判断：error，无依据的价格信息

### 8. 情绪化煽动
- 过度煽动情绪、使用极端化表述
- **示例问题**：
  - "震撼！！！" ← 过度煽动
  - "不买后悔一辈子" ← 极端化
  - 判断：warn，情绪化表述

---

## 不需要检查的内容（规则已覆盖）

- ❌ 明显违规词（最强/保证/吊打等，词表已检查）
- ❌ 竞品品牌名称（正则已检查）
- ❌ 伪造体验关键词（亲测/我用了等，正则已检查）

---

## 严重程度判断

- **error**：明显违规，必须修改
  - 变相绝对化、变相承诺
  - 无依据的价格、优惠、库存信息
  - 制造虚假紧迫感
  - 平台明确禁止的伪造体验

- **warn**：潜在风险，建议修改
  - 暗示性对比
  - 夸大效果
  - 情绪化表述
  - 表述不够严谨

---

## 输出格式

输出JSON数组，每个问题包含：
- `where`: 问题位置（如"标题"、"正文第2段"、"CTA"）
- `severity`: 严重程度（"error"或"warn"）
- `detail`: 具体问题描述
- `suggestion`: 修改建议

**没有问题时返回空数组**`{"issues":[]}`

```json
{
  "issues": [
    {
      "where": "标题",
      "severity": "error",
      "detail": "标题使用'无人能及'暗示绝对领先地位，属于变相绝对化表述",
      "suggestion": "改为有依据的具体描述，如'轻至980g'等客观参数"
    },
    {
      "where": "正文第4段",
      "severity": "warn",
      "detail": "'告别卡顿问题'暗示其他品牌有卡顿问题，属于隐性对比",
      "suggestion": "改为聚焦本产品特性，如'流畅运行多任务'"
    }
  ]
}
```
