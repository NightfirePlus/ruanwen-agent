要求：

1. 规划 3 至 8 个块，必须包含一个 `opening`、至少一个 `body` 和一个 `closing`。
2. `opening` 负责标题和导语，目标中必须明确两者都要生成；`body` 负责至少一个正文段落与配图；`closing` 负责行动引导和标签。块目标不得把结构要求缩减成“一句话”“仅标题”或“仅正文”。
3. 为每个正文块分配真正需要的事实编号，每块最多 3 条。不得创造事实编号。块目标只能要求这些事实直接支持的内容，不得要求模型从参数推导学习效率、便携收益、适用场所或使用体验。
4. 只有内容确实依赖另一个块已经通过时才填写 `depends_on`。相互独立的开篇和正文块不要添加依赖，以便生成与审核重叠执行；收束块可以依赖前面的内容块。
5. 块 ID 按最终文章顺序排列且不能重复。
6. 每个块必须且只能使用 `id`、`kind`、`objective`、`fact_ids`、`depends_on` 这些字段；不要改名为 `type`、`description`、`facts` 等近义字段。
7. 只返回如下结构的合法 JSON，不要使用 Markdown 代码围栏或附加说明：

{
  "blocks": [
    {
      "id": "B1",
      "kind": "opening",
      "objective": "形成标题和导语",
      "fact_ids": [],
      "depends_on": []
    }
  ]
}
