## 改写要求

1. **针对性修正**：
   - 逐条解决列出的问题
   - 按照问题的建议进行修改
   - error级别的问题必须修正，warn级别的问题建议修正

2. **保持整体结构**：
   - 不改变稿件的整体结构和风格
   - 不涉及问题的部分保持不变
   - 只修改有问题的地方

3. **事实准确**：
   - 删除无依据的表述
   - 补充缺失的条件和限制
   - 用客观描述替代夸大表述

4. **合规安全**：
   - 删除或改写违规表述
   - 避免暗示性对比和变相承诺
   - 聚焦产品本身，不贬低竞品

5. **完整输出**：
   - 返回完整的稿件JSON
   - 包含所有字段：title / intro / body / cta / tags / images / refusals
   - body数组中每段包含text和fact_ids
   - images数组中每张图片包含image_id / after_paragraph / caption / reason

---

## 输出格式

输出完整的稿件JSON，格式与compose.md相同：

```json
{
  "title": "修正后的标题",
  "intro": "修正后的导语",
  "body": [
    {"text": "修正后的第1段", "fact_ids": ["F1", "F2"]},
    {"text": "修正后的第2段", "fact_ids": ["F3"]}
  ],
  "cta": "修正后的行动引导",
  "tags": ["标签1", "标签2"],
  "images": [
    {
      "image_id": "I1",
      "after_paragraph": 1,
      "caption": "图片说明",
      "reason": "选择理由"
    }
  ],
  "refusals": []
}
```

---

## 注意事项

- 确保修正后的内容符合writer_system.md中的所有规则
- 所有产品信息必须有事实依据
- 图片ID必须来自原稿件的可用图片列表
- fact_ids必须准确标注引用的事实编号
- 输出纯JSON，不要包含markdown代码块标记
- JSON格式必须正确，可以被程序解析

---

## 改写策略示例

**问题**："标题使用'无人能及'暗示绝对领先地位"
**改写**：将"无人能及的轻薄体验"改为"整机重量约980g"（用具体参数替代绝对化表述）

**问题**："续航14小时未说明测试条件"
**改写**：将"续航14小时"改为"本地视频播放可达14小时"（补充测试条件）

**问题**："'告别卡顿问题'暗示其他品牌有卡顿"
**改写**：将"告别卡顿问题"改为"流畅运行多任务"（聚焦本产品特性）

**问题**："提到'适合3D渲染'但产品是轻薄本"
**改写**：删除3D渲染场景，改为"适合日常办公和轻度创作"（匹配产品定位）
