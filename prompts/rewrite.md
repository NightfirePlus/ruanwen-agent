要求：

1. 列出的每个问题都必须修正；若无法安全改写，就删除对应表述。
2. 只改动解决问题所需的内容，保留其他结构、事实编号和图片安排。
3. 所有修改仍须符合原始策略；只能使用本轮提供的事实编号和图片 ID，不用新的无依据表述替换旧问题。
4. 返回全部字段：`title`、`intro`、`body`、`cta`、`tags`、`images`、`refusals`。
5. `body` 元素包含 `text` 和 `fact_ids`；`images` 元素包含 `image_id`、`after_paragraph`、`caption` 和 `reason`。
   图片问题按定位处理：可调整位置、换用本轮已登记图片、修改图注或移除；不重复选图，不使用本轮清单外素材填补数量。当前不执行视觉模型审图，图注只依据登记说明且不能增加事实。表达参考不作为新产品参数的来源。
6. 返回且只返回一个合法 JSON 对象，不要使用 Markdown 代码围栏或附加说明。

  "tags": [],

  "refusals": []
}
