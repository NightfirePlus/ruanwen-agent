# 阶段2：从资料摘录事实点

<!--

请为目标型号从资料中逐字摘录可用于营销稿件的产品事实。

## 目标型号

{{型号}}

## 资料标题

{{资料标题}}

## 资料全文

{{资料全文}}

摘录规则：

1. 每条 `text` 必须是资料中连续、逐字一致的原文片段，不改写、不归纳、不补充。
2. 只摘录明确适用于目标型号的内容；其他型号、系列泛称、第三方观点和无来源评价不摘录。
3. 数值必须连同单位、配置、适用范围和测试条件一起摘录，不能截掉限定信息。
4. 优先摘录参数、功能、性能、兼容范围、设计特点和使用限制；排除营销形容词以及价格、优惠、库存和活动信息。
5. 同一参数存在互相矛盾的说法时，不放入 `facts`，在 `conflicts` 中说明冲突的两段原文。
6. 没有可用事实或冲突时，对应数组返回空数组。

返回且只返回一个合法 JSON 对象，不要使用 Markdown 代码围栏或附加说明：

{
  "facts": [{"text": "从本次资料全文逐字复制的片段"}],
  "conflicts": []
}
