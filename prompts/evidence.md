你的任务是从ima知识库资料中摘录关于特定型号的产品事实点，用于后续生成营销软文。

## 目标型号

{{型号}}

## 资料信息

资料标题: {{资料标题}}

资料全文:
{{资料全文}}

---

## 摘录要求

1. **逐字摘录**：
   - 每条事实必须**逐字**来自资料原文，不改写、不归纳、不推测
   - 摘录完整的句子或完整的描述，保留上下文
   - 包含数值时，必须保留原文的单位、条件、配置说明

2. **型号精确匹配**：
   - 只摘录**明确提到目标型号**的内容
   - 如果资料中提到其他型号（如相近系列、对比型号），**不要摘录**
   - 如果资料讲的是"某系列"而非具体型号，只有在明确说明适用于目标型号时才摘录

3. **优先摘录的内容**：
   - 产品参数：重量、尺寸、屏幕、处理器、内存、存储、续航等
   - 核心功能：特色功能、技术亮点、使用场景
   - 性能数据：测试结果、对比数据（必须包含测试条件）
   - 适用范围：兼容性、支持的系统/软件/外设
   - 设计特点：外观、材质、接口、散热等

4. **识别冲突**：
   - 如果资料中同一参数有不同数值（如续航时间有多个说法）
   - 如果资料中有自相矛盾的描述
   - 将冲突内容放入`conflicts`数组，不要放入`facts`

5. **不要摘录的内容**：
   - 营销性形容词（如"极致""完美""最强"）
   - 用户评价或第三方观点（除非明确标注来源）
   - 价格、优惠、库存、活动信息（这些会单独处理）
   - 提及其他品牌或其他型号的对比

## 输出格式

输出JSON，包含两个字段：

```json
{
  "facts": [
    {"text": "资料原文的完整句子1"},
    {"text": "资料原文的完整句子2"},
    {"text": "资料原文的完整句子3"}
  ],
  "conflicts": [
    "资料中自相矛盾的描述，说明具体位置和冲突内容"
  ]
}
```

## 示例

**资料原文**：
"MateBook X Pro 整机重量约980g，厚度13.5mm。配备14.2英寸3.1K OLED触控屏，支持10点触控。续航方面，本地视频播放可达14小时（实验室条件下，50%亮度）。"

**正确摘录**：
```json
{
  "facts": [
    {"text": "MateBook X Pro 整机重量约980g，厚度13.5mm"},
    {"text": "配备14.2英寸3.1K OLED触控屏，支持10点触控"},
    {"text": "本地视频播放可达14小时（实验室条件下，50%亮度）"}
  ],
  "conflicts": []
}
```

**错误做法**：
- ❌ "重量很轻" - 改写了原文
- ❌ "超长续航" - 归纳了原文
- ❌ "14小时续航" - 丢失了测试条件

型号:{{型号}}
资料标题:{{资料标题}}
资料全文:
{{资料全文}}
