# 当前知识库

本目录为唯一运行知识库，后续直接更新。共2520条资料：产品190、生态及支持197、人群场景162（30类行业包150、11份补充场景卡、1份总索引）、营销表达495、图片852、动态信息446、竞品资料178。动态信息包含426条历史价格和20份业务规则，历史价格快照按型号存放于 `06-动态信息/历史价格/<型号>/`；图片中845张有精确型号归属，7张为可人工选用的通用素材。库内不保留待确认或隔离内容。`catalog.json` 以 `source.locator_type` 区分 `local`、`url`、`historical` 三种来源位置。

项目的目标核心架构见 [核心架构规范](../../docs/core-architecture.md)，项目进度见 [项目进度](../../ROADMAP.md)，当前与目标运行差异见 [运行约定](../../docs/knowledge-runtime.md)。

内容边界见 `00-规范与索引/治理与使用规范.md`。必要来源和生命周期信息保存在 `catalog.json`，历史核验结论与候选修订保存在 `knowledge-verification.sqlite3`；横向比较使用自动生成的派生视图，不维护第二套事实。

全部2520条资料已补齐资料类型、入库时间、来源、核验要求和按类型配置的有效期元数据，这些元数据保存于 `catalog.json` 作为追溯信息。运行时完全信任知识库：产品事实按原文取用，营销表达与人群场景参考直接进入写作上下文，知识库阶段不调用任何模型，也不抓取官网。保留的确定性校验是 catalog 与文件哈希一致、型号归属、异常尺寸字段剔除和产品事实冲突检测。

25份生态能力卡共228条官网引文已完成自动逐字核验，状态为 `source_verified`；这不等于人工事实批准，因此仍保持 `publishable=false`。人工复核后才能按治理规则提升发布状态。
