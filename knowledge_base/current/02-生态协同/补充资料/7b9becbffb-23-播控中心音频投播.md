# 播控中心音频投播

- 官方页面：https://consumer.huawei.com/cn/support/content/zh-cn16091046/
- 抓取日期：2026-10-23

## 适用范围

| 字段 | 内容 |
|---|---|
| 主题 | 播控中心音频投播 |
| 适用产品（页面原文） | HUAWEI MatePad Edge 各 Wi-Fi 版本（含柔光屏、液冷版、含键盘套装等）；未列其他平板或 PC。 |
| 适用版本（页面原文） | HarmonyOS 6.0、HarmonyOS 6.1 |
| 证据抓取日期 | 2026-10-23 |

## 简短结论

播控中心在 HUAWEI MatePad Edge 上控制音视频应用，并可把本机音频投播至耳机、音箱、智慧屏等设备。锁屏播控仅限平板模式，且并非所有应用支持。该能力是音频投播，不是屏幕镜像。

## 设备与前置条件

### 主机端

- HUAWEI MatePad Edge；HarmonyOS 6.0/6.1。

### 音频设备

- 耳机、音箱、智慧屏等；需先连接或在智慧生活中添加。

## 操作路径

- 连接音频设备。
- 平板模式从顶部右侧下滑控制中心；电脑模式点右下角状态栏中间区域。
- 点击播控中心空白处进入。
- 控制播放/音量/进度/曲目。
- 点右上角图标选择投播设备；无列表时点切换。
- 锁屏时在平板模式上滑实况窗胶囊。

## 限制

- 仅 MatePad Edge。
- 仅 HarmonyOS 6.0/6.1。
- 并非所有应用支持。
- 锁屏播控仅平板模式。
- 音频投播，不是投屏。
- 设备型号未列。

## 不能从本卡直接推出

- 不能推出所有华为平板支持。
- 不能推出 PC 支持。
- 不能推出所有应用支持。
- 不能推出电脑模式锁屏播控。
- 不能把播控中心写成屏幕镜像。
- 不能推出所有音频设备/协议支持。
