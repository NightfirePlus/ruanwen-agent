# 多屏协同多窗口与横屏大窗口

## 简短结论

两个页面分别说明多屏协同的手机应用多窗口和 Windows 电脑横屏大窗口。多窗口可把手机应用以分身子窗口打开，部分应用在 Windows 上以横屏大窗口显示。应用锁、锁屏、冻屏、应用支持范围、窗口数量上限和 USB 有线连接均有限制；页面未给具体窗口数量。

## 设备与前置条件

### 手机

- 支持多屏协同；横屏大窗口还需手机支持该能力。

### 平板/Windows 电脑

- 平板按多屏协同连接；横屏大窗口为华为 Windows 10/11 电脑。
- 电脑管家 13.0.3.320+。

## 操作路径

- 手机与平板/Windows 电脑建立多屏协同。
- 在镜像窗口打开应用，点击分身按钮。
- 部分机型可长按应用图标 > 在新窗口打开。
- Windows 上部分应用子窗口以横屏大窗口显示。
- 调整窗口大小/位置，或固定在最前端。

## 限制

- 多窗口页版本范围 HarmonyOS 2.0–4.3 等；横屏大窗口页 Windows 10/11。
- 长按新窗口打开仅部分机型。
- 仅部分应用支持分身/横屏大窗口。
- 应用锁、锁屏、冻屏不支持分身。
- 窗口数量有上限，页面未给数字。
- 横屏大窗口不能切竖屏。
- USB 有线连接不支持横屏大窗口。
- 通知仍在主窗口显示。

## 不能从本卡直接推出

- 不能推出所有鸿蒙版本支持多窗口。
- 不能推出所有应用支持分身或横屏大窗口。
- 不能推出应用锁解锁后可分身。
- 不能推出锁屏/冻屏可分身。
- 不能写出具体窗口数量上限。
- 不能推出横屏大窗口可切竖屏。
- 不能推出 USB 有线连接支持横屏大窗口。
- 不能把本卡写成鸿蒙电脑键鼠共享或平板扩展屏。
