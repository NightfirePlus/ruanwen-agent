## 设备组合

### 主机端（华为计算机）

- Windows 计算机（装有华为电脑管家）。

### 对端（显示器/智慧屏）

- **仅**华为 MateView（无线投屏版）显示器和**部分**智慧屏支持此功能。
- 官网未列全部支持型号清单，文案不得外推到所有智慧屏。

## 前置条件

- 显示器：开机状态下，没有通过有线或无线的方式连接至其他设备。
- 智慧屏：开机状态下，打开蓝牙开关，确保智慧屏为亮屏解锁状态，且没有通过有线或无线的方式连接至其他设备。
- 电脑：开机状态下，且没有通过有线的方式连接其他设备，打开蓝牙开关，将蓝牙驱动升级至最新版本，将 Windows 系统更新到最新版本。

## 操作步骤摘要

- 华为电脑管家 → 我的设备 > 我的显示设备 > 立即连接 → 在待连接列表中选择显示器/智慧屏名称。
- 首次连接时，在计算机对话框中输入显示器/智慧屏上弹出的 PIN 码，按屏幕提示完成连接。
- 选择协同方式：镜像（显示与计算机桌面相同的内容）或扩展（延伸计算机屏幕）。
- 无论何种模式下，都可以使用计算机或显示器/智慧屏的键鼠，同时操作计算机和显示器/智慧屏。
- 屏幕排列方向、显示分辨率、音频输入输出设备等在"协同设置"中调整。

## 限制

- 协同状态下，不支持调用智慧屏摄像头。
- 仅华为 MateView（无线投屏版）显示器和部分智慧屏支持此功能。

## 可发布主张（publishable_claims）

- 华为 MateView（无线投屏版）显示器及部分智慧屏可与华为 Windows 电脑建立协同连接，选择镜像或扩展模式实现双屏办公。
- 协同后可使用计算机或显示器/智慧屏的键鼠同时操作两端设备。

## 禁用主张（blocked_claims）

- "所有显示器/所有智慧屏都能与电脑协同"——官方明确仅 MateView（无线投屏版）和部分智慧屏支持。
- "协同状态下可以使用智慧屏摄像头"——官方明确不支持。
- "即连即用、无需更新"——官方要求蓝牙驱动与 Windows 系统更新到最新。
