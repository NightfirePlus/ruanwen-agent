## 设备组合

### 主机端（华为计算机）

- Windows 计算机（装有华为电脑管家；官网可按机型查询对应电脑管家版本）。

### 对端

- 华为手机（手机端参与传输的服务为 Huawei Share（华为分享））。

## 能力概述

- 计算机与手机之间通过一碰传/多屏协同传输图片、视频、文档。
- 传输通道由计算机与手机通过 WLAN 底层 P2P 配对建立；手机端 Huawei Share（华为分享）参与运行。

## 前置条件

- 华为电脑管家为最新版本（华为官网可查询机型对应的电脑管家版本）。
- 计算机与手机 WLAN 正常（虚拟网卡状态正常）。
- 计算机端防火墙未阻断。
- 文件打开方式符合官方要求（见"限制"）。

## 操作步骤摘要（连接与传输）

- 通过华为电脑管家完成手机与计算机连接后，在手机/计算机间一碰传或拖拽传输图片、视频、文档。
- 传输失败时官方排查顺序：检查电脑管家版本 → 重启计算机虚拟网卡并重置两端网络 → 清除手机 Huawei Share（华为分享）缓存 → 还原防火墙 → 核对文件打开方式。

## 限制

- 文件打开方式有官方硬性要求：计算机打开图片必须用华为图片查看器，视频必须用 Huawei image viewer，PDF 必须用 Edge 浏览器；手机端必须用图库/WPS 打开文件。
- 一碰传文件失败时，打开方式不正确是官方列出的独立原因之一。
- 手机"还原网络设置"会还原 WLAN、移动数据网络、蓝牙、星闪的全部设置（不删除其他数据）。
- 本卡证据来自官方排障页，未给出具体支持机型清单。

## 可发布主张（publishable_claims）

- 华为 Windows 计算机与华为手机之间支持一碰传/多屏协同传输图片、视频、文档（经华为电脑管家连接，WLAN P2P 通道传输）。
- 官方提供完整传输失败排查路径（管家版本、网络、华为分享缓存、防火墙、打开方式）。
