# 多屏协同：多窗口与横屏大窗口（手机 + 平板/Windows 电脑）

## 设备组合

### 发起端（手机）

- 支持多屏协同的华为手机；横屏大窗口还要求手机支持"横屏大窗口"，具体机型和版本需查页面所指清单。
- 多窗口页适用 HarmonyOS 2.0/2.1/2.0.1/3.0/3.1/4.0/4.2/4.3、Magic UI 4.0、EMUI 11.0；横屏大窗口页没有单独列手机版本，只要求手机支持该能力。

### 对端（平板/Windows 电脑）

- 平板或 PC 作为多屏协同的显示端；横屏大窗口页明确为华为 Windows 10/11 计算机（台式机或笔记本）。
- Windows 端需华为电脑管家保持开启，版本 13.0.3.320 及以上。

### 连接方式

- 手机与 Windows 电脑可通过 NFC 碰一碰（仅部分支持 NFC 的手机）或华为电脑管家连接；平板侧按多屏协同方式连接。
- 手机与计算机通过 USB 有线方式连接时，不支持横屏大窗口。

## 能力概述

- 多窗口：在手机镜像窗口中打开应用的分身子窗口，可同时操作多个手机应用；子窗口保持打开时的最大化/窗口化/横屏/竖屏状态。
- 横屏大窗口：在华为 Windows 电脑上，部分应用的分身子窗口会以横屏大窗口显示，便于查看更多内容。
- 子窗口可调整大小、返回上一级、移动位置、固定在最前端；应用通知仍显示在主窗口。
- 页面没有给出子窗口数量上限的具体数字，只说明达到上限会提示"窗口数量已达上限"。

## 前置条件

- 手机支持多屏协同；使用横屏大窗口时，手机还需支持"横屏大窗口"，并核对页面所指机型和版本清单。
- Windows 电脑为 Windows 10/11，华为电脑管家保持开启且版本 13.0.3.320 及以上。
- NFC 连接：手机支持 NFC、处于解锁状态，手机开启 WLAN/蓝牙/NFC，电脑开启 WLAN/蓝牙。
- 电脑管家连接：手机和电脑开启 WLAN/蓝牙；若手机为 HarmonyOS 5 及以上，手机和电脑需登录相同华为账号。
- 先建立手机与平板/电脑的多屏协同连接。

## 操作步骤摘要

- 通过 NFC 碰一碰或华为电脑管家，把手机与 Windows 电脑建立多屏协同；平板侧按多屏协同方式连接。
- 在手机镜像窗口中打开应用。
- 点击镜像窗口顶部的分身按钮，打开该应用的分身子窗口；部分机型也可在手机桌面长按应用图标，点击"在新窗口打开"。
- 在 Windows 电脑上，部分应用的分身子窗口会以横屏大窗口显示。
- 调整窗口大小/位置，或点击窗口顶部"固定在最前端"。
- 关闭子窗口：点击主窗口或手机中该应用图标、子窗口关闭按钮、多任务卡片、全局搜索、长按应用图标选快捷菜单等。

## 限制

- 多窗口页适用版本为 HarmonyOS 2.0/2.1/2.0.1/3.0/3.1/4.0/4.2/4.3、Magic UI 4.0、EMUI 11.0；横屏大窗口页适用 Windows 10/11。两页版本口径不同，不能合并成"所有版本都支持"。
- 长按应用图标"在新窗口打开"仅部分机型支持；无该选项即不支持。
- 部分应用分身按钮置灰，提示"暂不支持在新窗口打开"。
- 设置了应用锁的应用不支持分身，解锁后也不支持。
- 锁屏界面不支持分身；冻屏界面不支持分身，且只保留主窗口冻屏界面，恢复连接后子窗口不恢复。
- 子窗口数量有上限，但页面未给具体数字；不能写"最多 N 个"。
- 仅部分应用支持横屏大窗口；横屏大窗口不支持切换为竖屏窗口。
- 手机与计算机通过 USB 有线连接时，不支持横屏大窗口。
- 应用在子窗口打开后，通知仍显示在主窗口。
- 本卡是多屏协同的手机应用多窗口/横屏大窗口，不是鸿蒙电脑键鼠共享，也不是平板作电脑扩展屏。

## 可发布主张（publishable_claims）

- 支持多屏协同的华为手机与平板/Windows 电脑连接后，可在手机镜像窗口中打开应用分身子窗口，实现多应用同时操作。
- 在华为 Windows 10/11 电脑上，部分应用的分身子窗口会以横屏大窗口显示；仅部分应用支持，且不能切回竖屏窗口。
- 子窗口数量有上限、应用锁/锁屏/冻屏等场景不支持分身；页面未给具体数量上限。

## 禁用主张（blocked_claims）

- "所有鸿蒙版本都支持多窗口"——多窗口页只列 HarmonyOS 2.0–4.3、Magic UI 4.0、EMUI 11.0。
- "所有应用都能分身/横屏大窗口"——页面明确仅部分应用。
- "应用锁解锁后就能分身"——页面明确仍不支持。
- "锁屏/冻屏也能分身"——页面明确不支持。
- "最多可以开 N 个窗口"——页面未给具体数字，不能补写。
- "横屏大窗口可以切竖屏"——页面明确不支持。
- "USB 有线连接也支持横屏大窗口"——页面明确不支持。
- "这是鸿蒙电脑键鼠共享/平板扩展屏"——本卡是多屏协同的手机应用多窗口。
