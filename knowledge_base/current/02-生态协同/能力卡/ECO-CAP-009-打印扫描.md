## 设备组合

### 主机端（华为计算机）

- Windows 计算机 / 鸿蒙电脑（平板电脑操作可能有部分差异）。

### 对端

- 打印机、扫描仪（含其他品牌）。

## 能力概述

- Windows 计算机：支持 USB 有线连接、无线局域网连接、共享方式连接打印机；可将已连接打印机的 A 计算机的打印机共享给同一局域网中的 B 计算机。
- 鸿蒙电脑：支持 WiFi/网络连接、IP 添加、USB 连接三种方式；支持智睦云打印（(Cloud) 开头云打印打印机）。

## 前置条件

- WiFi 连接：电脑和打印机/扫描仪必须连同一个 WiFi；部分打印机/扫描仪不支持 5G WiFi，需双方同时连接 2.4G WiFi。
- 共享打印：A、B 计算机在同一局域网或工作组；开启网络发现和文件和打印机共享；勾选 SMB 1.0/CIFS 文件共享支持（Win11 24H2 需关闭 SMB 签名）。
- 品牌打印机需安装对应驱动。

## 操作步骤摘要

- 打印入口：WPS 等应用中右键选择打印、Ctrl+P 快捷键或分享按钮选择打印；打印预览界面可选打印机、页面范围、打印份数、纸张参数，系统根据打印机能力显示打印色彩、打印质量和单双面选项，参数调整时左侧预览图实时查看。
- 共享打印：A 计算机打印机属性勾选"共享这台打印机"→ B 计算机按名称选择共享打印机（输入 \\IP 或主机名）→ 凭据登录 → 打印测试页。
- 鸿蒙电脑网络连接失败时：可安装"智睦云打印"驱动 APP 添加打印机，成功后选择 (Cloud) 开头打印机打印。

## 限制

- 华为计算机无法连接打印机时官方常见原因：驱动未正确安装、Windows 系统故障；近期更新过系统时需关闭"受 Windows 保护的打印模式"。
- 鸿蒙电脑外设若暂未适配，可在《鸿蒙电脑外设兼容清单》"加入心愿单"反馈设备型号，官方推进适配；清单外设备不保证可用。
- 部分打印机/扫描仪不支持 5G WiFi（需 2.4G WiFi）。
- 官方教程以其他品牌打印机（如惠普 P1106）为例，连接前需从打印机品牌官网下载对应驱动。

## 可发布主张（publishable_claims）

- 华为 Windows 计算机支持 USB、无线、局域网共享三种方式连接打印机；鸿蒙电脑支持 WiFi/IP/USB 连接及智睦云打印。
- 打印支持在 WPS 等应用中右键/Ctrl+P/分享入口发起，可调整页面范围、份数、纸张及打印机能力支持的色彩、质量、单双面参数。

## 禁用主张（blocked_claims）

- "任何打印机都能连华为电脑"——官方以兼容清单/驱动适配为准，未适配设备需心愿单反馈。
- "打印机连任意 WiFi 都能用"——官方明确电脑与打印机必须同一 WiFi，部分打印机仅支持 2.4G WiFi。
- "即插即用、无需驱动"——官方明确需安装对应品牌驱动（及可能的智睦云打印驱动）。
