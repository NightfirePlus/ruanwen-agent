# 多屏协同：手机投至平板（HarmonyOS 5）

- **能力编号**：ECO-CAP-015
- **能力类别**：生态协同
- **复核状态**：pending_review（待人工复核）
- **证据抓取日期**：2026-10-23

## 设备组合

### 主机端（平板）

- 页面适用产品清单列出的 HUAWEI MatePad 11.5"S、MatePad 11.5 S（含灵动款）、MatePad Air、MatePad 11.5、MatePad Pro、华为擎云 C9 等。
- 平板系统版本为 HarmonyOS 5.0 或 5.1。

### 对端（手机）

- 华为手机；需与平板登录同一华为账号，并开启蓝牙、WLAN。
- 页面未单独列出手机型号清单，不能把平板清单当作手机清单。

### 连接方式

- 超级终端连接；若平板配套键盘支持 NFC，也可通过键盘一碰连接。

## 能力概述

- 官方定义："将手机和平板建立协同连接，在平板上可镜像显示手机窗口、使用手机应用、编辑手机文件等，还可拖拽互传文件，协同使用更高效。"
- 协同后可在平板上查看手机部分通知（如短信、畅连），并在手机解锁状态下打开电话、信息、畅连、图库或文件管理。
- 支持在手机与平板之间拖拽互传图片、视频、文档，也可把手机内容拖入平板正在编辑的备忘录或邮件。

## 前置条件

- 手机和平板开启蓝牙、WLAN。
- 手机和平板登录同一华为账号。
- 海外华为账号暂不支持在多屏协同中使用。
- NFC 一碰连接要求平板配套键盘支持 NFC，且键盘已与平板连接成功。

## 操作步骤摘要

- 超级终端：从手机顶部右侧下滑出控制中心 → 在"超级终端"中点击平板图标/协同设备名称 → 发起协同连接。
- NFC 一碰：手机开启蓝牙、WLAN、NFC → 用手机 NFC 区域触碰键盘 NFC 区域，保持至提示音或振动 → 按手机和平板弹框提示完成连接。
- 在平板的手机镜像窗口打开电话、信息、畅连、图库或文件管理，操作手机应用和文件。
- 拖拽互传：在手机镜像窗口长按图片/视频/文件 → 多选 → 再次长按至悬浮 → 拖拽至平板；反向同理。
- 断开：在平板手机镜像窗口点击关闭；或点击手机顶部协同中胶囊/通知中心协同通知/超级终端中的平板图标取消。

## 限制

- 仅 HarmonyOS 5.0/5.1，且平板为页面适用产品清单列出的型号；未列型号不得推断。
- 海外华为账号暂不支持多屏协同。
- 页面明确"当手机屏幕处于解锁状态时"才能在平板镜像窗口打开电话、信息、畅连、图库等；锁屏状态下的可用范围未展开。
- 平板只能查看手机"部分通知消息（如短信、畅连）"，不能写成全部通知。
- NFC 一碰连接依赖支持 NFC 的平板配套键盘。
- 本页是手机投至平板；不能推出手机投至电脑、平板投至电脑或平板作扩展屏。

## 可发布主张（publishable_claims）

- HarmonyOS 5.0/5.1 的指定华为平板与可支持多屏协同的华为手机（手机型号未在本页单列），在登录同一华为账号、开启蓝牙和 WLAN 后，可通过超级终端建立多屏协同。
- 协同后平板可镜像显示手机窗口、使用手机应用、编辑手机文件，并在设备间拖拽互传图片、视频、文档。
- 平板配套键盘支持 NFC 时，可通过手机触碰键盘完成一碰连接。

## 禁用主张（blocked_claims）

- "所有华为平板都支持"——页面只列 MatePad 11.5"S、MatePad 11.5 S、MatePad Air、MatePad 11.5、MatePad Pro、擎云 C9 等清单型号。
- "所有华为手机都支持"——页面未单列手机型号清单，不能外推。
- "海外华为账号也能用"——页面明确暂不支持。
- "锁屏也能在平板上操作全部手机应用"——页面只描述手机解锁状态下的操作。
- "平板能看到手机全部通知"——页面只写部分通知（如短信、畅连）。
- "手机能投到电脑/平板能当电脑扩展屏"——本页未涉及。
