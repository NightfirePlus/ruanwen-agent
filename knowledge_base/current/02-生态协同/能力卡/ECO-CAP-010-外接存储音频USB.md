## 设备组合

### 主机端（华为计算机）

- 鸿蒙电脑（外接存储/音频）与 Windows 计算机（USB 设备排查）。

### 对端

- U 盘、移动硬盘、读卡器等外接存储设备；USB 音频设备（耳机、麦克风、音响）。

## 能力概述

- 鸿蒙电脑支持外接存储设备（文件管理查看/格式化/安全移除）与 USB 音频设备——官方原文："鸿蒙电脑支持USB音频设备，无需安装额外驱动即能兼容市面上大部分音频外设。"

## 前置条件

- 外接存储文件系统：支持 NTFS、exFAT、Vfat(FAT32)；不支持 ext4、APFS/HFS+。
- 外接存储设备复制粘贴过程中不要移除外接存储设备；使用完成后断开前需安全移除。
- USB 音频设备：通电、接口正常供电；若用扩展坞转接需接口支持数据传输。

## 操作步骤摘要

- 插入存储设备后，通过桌面快捷栏文件管理或"鸿蒙键 + F"打开文件管理，导航栏查看；底部信息栏显示总空间和可用空间。
- 格式化：文件管理 > 存储位置 > 右键选择外接设备 > 格式化 > 选择目标格式 > 开始格式化（建议先备份数据）。
- 安全移除：文件管理 > 存储位置 > 右键移除，或通知中心选择移除；提示"设备已安全移除"后断开。
- Windows 计算机 USB 无法识别时：换机交叉测试 → 检查插接状态/换接口 → 移动硬盘经扩展坞时连接电源线 → 卸载"USB 大容量存储设备"后重插 → 禁用"USB 选择性暂停设置" → 格式化。

## 限制

- FAT32 单个文件不能大于 4G，否则传输失败。
- FAT32 外接存储设备不支持热插拔，需安全移除，否则可能导致数据丢失。
- 鸿蒙电脑暂不支持加密过的存储设备；不支持识别 Windows 动态磁盘（需转换为基本磁盘，转换会清除数据）。
- 鸿蒙电脑不支持模拟耳机（提示"不支持当前接入的音频设备"时，更换随机附赠耳机或使用 TypeC 转 3.5mm 数字转接头）。
- 外设兼容性以《鸿蒙电脑外设兼容清单》为准，清单外设备可通过心愿单反馈适配。

## 可发布主张（publishable_claims）

- 鸿蒙电脑支持 NTFS、exFAT、FAT32 文件系统的 U 盘/移动硬盘/读卡器，可在文件管理中查看、格式化并安全移除。
- 鸿蒙电脑支持 USB 音频设备，无需额外驱动即可兼容市面上大部分音频外设。

## 禁用主张（blocked_claims）

- "任意格式的移动硬盘/U 盘都能直接使用"——ext4、APFS/HFS+ 明确不支持；加密盘、动态磁盘不支持。
- "FAT32 盘随便传大文件"——单个文件超过 4G 传输失败。
- "外接设备可以随时热插拔"——官方明确复制过程中不可移除、断开前需安全移除。
- "任何 3.5mm 耳机都能插上就用"——鸿蒙电脑不支持模拟耳机，需数字转接头。
