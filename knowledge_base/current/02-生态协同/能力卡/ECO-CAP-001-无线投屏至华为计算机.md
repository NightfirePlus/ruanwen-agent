## 前置条件

- 计算机开启 WLAN 和蓝牙。
- 首次使用需在"可选功能"中添加"无线显示器"并重启计算机。
- 已设置"投影到此电脑"权限，并记住当前电脑名称。
- 对端设备打开无线投屏后能搜索到该计算机名称。

## 操作步骤摘要

- 计算机端：Win+I → 系统 → 投影到此电脑 → 启动"连接"应用（首次使用先添加"无线显示器"可选功能并重启）。
- 对端设备：打开无线投屏模式 → 搜索并选择计算机名称 → 连接。
- 断开：在手机端点击投屏按钮即可关闭。

## 限制

- 通过华为电脑管家将手机与计算机连接，可能会影响手机的无线投屏功能；需在"我的设备＞我的手机＞断开连接"中断开，并在计算机端关闭"连接"窗口后重试。
- 部分机型的手机投屏后无"电脑模式"选项，请以实际界面为准。
- 页面示例 OPPO R11 Plus 仅支持投屏到电视、电视盒子；投屏到计算机需下载单独的投屏软件。
- 不同设备打开无线投屏模式的操作不一样，具体请咨询设备供应商。
- 投屏卡顿、花屏与网络带宽、路由器接入设备数量、WLAN 信号质量、视频分辨率有关；官方建议连接 5G WLAN 频段、与被投屏设备保持 1-3 米距离。
- 微软 Windows 系统与投屏设备的兼容性问题也可能导致卡顿花屏。

## 可发布主张（publishable_claims）

- 华为 Windows 10/11 笔记本、台式机可作为无线投屏接收端（需开启 WLAN、蓝牙并设置投影权限；首次使用需添加"无线显示器"可选功能）。
- 投屏体验受网络带宽、WLAN 信号质量和视频分辨率影响，官方建议连接 5G WLAN 并保持 1-3 米距离。
