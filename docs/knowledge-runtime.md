# 知识库与模型运行约定

本文件只维护当前约定，直接更新，不另存版本。项目进度统一见 [项目进度](../ROADMAP.md)。

## 数据与存放位置

唯一运行目录为 `knowledge_base/current`，可通过 `KB_LOCAL_DIR` 指定同结构的实际位置。原库、旧快照、迁移工具和无效内容均已删除；项目历史资料单独存放在 `archive/`，不参与运行。

当前包含2520条资料：产品190、生态及支持197、人群场景162、营销表达495、图片852、动态信息446、竞品资料178。已登记53个型号/系列；84份扩展产品发现卡不能替代正式规格。竞品资料只在明确比较意图下提供对比框架和待核线索，对外竞品事实仍需重新打开对应品牌官网核对。

图片中845张有精确型号登记，可进入自动配图；7张通用素材只供人工挑选。待确认、错位隔离和旧销售快照均不保留。动态信息包含426条历史价格及20份业务登记/复核模板：历史价格可用于趋势与追溯，但不能作为当前价格；模板不含实际值。画像、范文、排障、竞品参考和营销参考不作为主推产品事实。

来源、行号、哈希、来源纠正和图片原索引记录保留在 `00-规范与索引/catalog.json`，产品来源表保留在该目录的 `来源登记/`，它们是必要追溯数据。`source.locator_type` 区分 `local`、`url`、`historical` 三种来源位置；`historical` 只保留旧库追溯信息，不代表当前仍可读取。内容治理只维护 `治理与使用规范.md`，`runtime-policy.json` 保存执行参数，`usage-review.sqlite3` 保存审核标记；`派生视图/产品横向检索.json` 从产品事实自动生成，不作为第二事实源。

## 审核与复用

入库由外部负责。本项目执行：检索相关文字资料 → 检查版本与审核标记 → 仅审核未检查或已变化的文字资料 → 保存结论 → 读取精确型号已登记图片 → 写作 → 核验当前稿件。

文字审核记录绑定文件、标注、型号/配置、来源、相关产品依据、提示词、模型与规则版本。未变化则复用；文件修改需同步对应来源与catalog哈希，未同步则拒绝读取。原文只读，标记写入独立审核索引。图片不写模型审核记录。

`passed`表示内部一致性与使用边界复核允许使用，不代表官网、授权或人工复核已经完成。`uncertain/rejected`复用为排除结果。失败或中断不得写成通过；并发请求先持久化占位，避免重复调用。

`python tools/knowledge_review.py` 查看当前标记。查明原因后，可用 `--reset 缓存key` 清除某条非通过记录，供下次使用重审；不自动发请求，不清除通过记录。

产品摘录必须能还原成连续原文；只允许排版空白差异，不接受改写。可疑尺寸字段停止使用，确认后才可修正。参考资料只提供表达与问题提示。每篇稿件仍检查当前型号、适用条件、图注与图文对应，素材曾通过不代表适合所有文章。

## 模型职责

| 模型 | 职责 |
|---|---|
| Qwen/Qwen3.5-35B-A3B | 需求理解、修改意图 |
| Qwen/Qwen3.5-397B-A17B | 图文写作、选图建议与局部改写 |
| ZhipuAI/GLM-5.2 | 首次资料复核、原文摘录、每篇事实与合规核验 |

图片暂不发送给视觉模型。运行时仅使用 `registered_image`、精确绑定当前型号且文件哈希与索引一致的素材；通用素材不自动使用。图片登记说明只用于选图和中性图注，不能作为产品参数、性能或效果依据。

写作接收已确认事实、表达参考和图片登记说明。最终核验接收相关原文、排除内容和图片登记，覆盖正文及图注。程序检查ID、型号、数量、重复与插入位置。新库强制严格核验。

## 成本与维护

默认每轮最多新增3次文字知识复核：产品事实1份、表达参考最多2份。图片最多选2张但不调用模型。缓存齐备后不重复文字资料审核；需求、写作和成稿核验照常。可通过 `KB_REVIEW_MAX_CALLS`、`KB_REFERENCE_LIMIT`、`KB_IMAGE_LIMIT` 收紧数量。

分工模式关闭接口重试与JSON自动修复；稿件问题最多改写两轮。没有已登记图片时明确说明，不编造素材凑数。审核模型仍可能出错，需用实际稿件持续验证。

`python tools/validate_knowledge_base.py` 校验当前库的文件、索引、来源位置与内部链接，无需旧库，不调用模型。

当前库 `knowledge_base/current` 随仓库发布，令牌和运行时审核数据库不提交。`archive/` 仅保存必要的项目发展记录，不进入部署与检索。部署时让审核索引所在目录可写且持久化。模型或提示词调整后重启应用。
