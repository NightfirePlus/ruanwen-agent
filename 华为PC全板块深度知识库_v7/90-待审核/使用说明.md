# 待审核区使用说明

本目录用于存放来源未确认、网页已变化、字段冲突、等待内部授权或尚未完成实测的资料。文件名建议采用“板块—主题—日期—待核验原因”，正文必须列出已有证据、冲突点、责任人和计划复核日期。

智能体默认不得把本目录内容作为确定事实引用。复核通过后移入 00 或 P1—P8 的对应目录并更新来源日期；确认错误、过期或无法继续验证的内容转入历史归档，同时保留处理记录。

## 进入待审核区的条件

- 官方页面无法访问、页面标题与内容不一致，或来源主体无法确认。
- 同一型号在产品页、规格页、商城页或支持页出现冲突字段。
- 只有系列级“最高/可选”信息，无法对应具体销售 SKU。
- 软件、驱动、外设或企业环境尚未完成目标版本的验证。
- 图片无法确认产品、原始 URL、权利状态或画面中的动态信息已经过期。
- 价格、库存、补贴、赠品、服务和内部政策缺少授权、地区、渠道或有效期。
- 客户案例、评价、测试数据、人物或截图尚未取得授权或完成脱敏。

## 文件最少字段

每个待审核文件至少写明：原板块、主题、发现日期、提交人、已有来源、现有结论、冲突或缺口、可能影响、禁止使用范围、需补证材料、责任人、计划复核日期和最终去向。附件不应直接包含账号、密钥、客户数据或内部报价；敏感材料只登记受控位置。

## 复核流程

1. 先锁定完整产品名、SKU、系统、地区、页面日期和任务，确认不是比较了不同对象。
2. 按权威等级检查官方产品/规格/支持页、软件或外设厂商文档及获授权内部记录。
3. 若需要实测，固定设备、版本、账号、网络、外设和样例，保存操作步骤与失败信息。
4. 复核人给出“通过、部分通过、无法确认、确认错误”之一，并说明证据。
5. 通过的内容移入对应正式板块；部分通过只移动已确认部分，其余继续保留；错误或失效内容进入 99。
6. 更新相关索引、来源总表、版本记录和引用该内容的下游文件。

## 智能体调用规则

检索命中本目录时，不输出为确定事实，也不与正式资料合并成完整答案。可以说明“知识库存在一条待审核记录”，列出需要人工确认的问题，并继续从正式板块寻找可用证据。若用户明确要求查看待审核过程，必须同时展示状态、日期和不能使用的范围。

## 退出检查

- [ ] 结论与具体对象、版本、时间和来源绑定。
- [ ] 冲突已解释，未通过删除限制条件来制造一致。
- [ ] 本地路径、索引和引用已更新且可打开。
- [ ] 动态信息有失效时间，敏感信息没有进入公开共享库。
- [ ] 复核人和处理日期已记录，后续复核责任明确。
