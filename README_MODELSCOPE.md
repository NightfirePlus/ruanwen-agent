# 魔搭平台部署说明

## 快速部署

### 1. 上传代码
将整个项目上传到魔搭平台，或使用Git仓库地址：
```
https://github.com/NightfirePlus/ruanwen-agent.git
```

### 2. 配置环境变量
在魔搭平台的"环境变量"设置中添加：

```bash
# ima共享知识库凭证（必需）
IMA_OPENAPI_CLIENTID=your_client_id
IMA_OPENAPI_APIKEY=your_api_key

# LLM接口配置（必需）
LLM_API_KEY=your_llm_api_key
LLM_BASE_URL=https://your-llm-endpoint.com/v1
LLM_MODEL=your-model-name

# 可选配置
PROMPTS_DIR=./prompts  # 提示词目录，默认使用项目的prompts/
```

### 3. 启动命令
在魔搭平台的"启动命令"中填写：
```bash
python app.py
```

### 4. 端口配置
确保魔搭平台端口设置为 `7860`（Gradio默认端口）

- 自然语言输入需求

## 技术架构

```
用户输入
  ↓
需求理解 (intake.md)
  ↓
场景匹配 + ima资料检索
  ↓
事实摘录 (evidence.md)
  ↓
图文生成 (compose.md + writer_system.md)
  ↓
事实核验 (fact_review.md)
  ↓
合规检查 (compliance_review.md)
  ↓
用户确认 / 修改意图判断 (revise_intent.md)
  ↓
按问题改写 (rewrite.md) / 重新生成
  ↓
最终输出
```

## 注意事项

1. **凭证安全**
   - 不要在代码中硬编码API Key
   - 使用魔搭平台的环境变量功能
   - 不要在界面上显示完整密钥

2. **知识库权限**
   - 确保Client ID对应的账号已加入ima共享知识库
   - 知识库名称：任德耀新建华为PC知识库

3. **资源限制**
   - 首次运行会加载所有提示词，可能需要几秒
   - 每次生成调用多个LLM接口，注意配额
   - 建议使用支持高并发的LLM服务

4. **错误处理**
   - 界面会捕获并显示错误信息
   - 检查环境变量配置是否正确
   - 查看魔搭平台日志排查问题

## 本地测试

在本地测试时：

1. 安装依赖：
```bash
pip install -r requirements.txt
```

2. 创建`.env`文件并配置环境变量

3. 启动应用：
```bash
python app.py
```

4. 访问：http://localhost:7860
