# 魔搭创空间部署说明

## 快速部署

### 1. 上传代码与知识库
将整个项目上传到魔搭创空间。项目使用**本地知识库目录**,不调用 ima 接口:

- 默认知识库路径:`<项目根>/华为PC全板块深度知识库_v7`
- 或者上传到任意目录,并用环境变量 `KB_LOCAL_DIR` 指向它

知识库目录只读取 `P1-产品参数库` 下包含 `产品事实.md` 的型号目录,其他板块不读。

### 2. 配置环境变量
在创空间的"环境变量"设置中添加:

```bash
# 大模型接口(必需,OpenAI 兼容)
LLM_API_KEY=your_llm_api_key
LLM_BASE_URL=https://your-llm-endpoint.com/v1
LLM_MODEL=your-model-name

# 本地知识库目录(可选;不设置时用项目内默认目录)
KB_LOCAL_DIR=/path/to/华为PC全板块深度知识库_v7

# 提示词目录(可选;默认使用项目内 prompts/)
PROMPTS_DIR=./prompts

# 网页默认宽松核验：规则错误仍修正，模型意见作为提示展示
# 需要原先严格模式时改为 strict
REVIEW_MODE=relaxed
```

网页生成成功后，可下载纯文案 TXT 或包含资料依据、核验提示的完整 Markdown 报告。
被阻断的请求会展示具体问题，并在服务器 `samples/web-*.json` 留存诊断记录。

### 3. 启动命令
```bash
python app.py
```

### 4. 端口配置
创空间端口设置为 `7860`(Gradio 默认端口;可用环境变量 `PORT` 覆盖)。

### 5. 依赖
`requirements.txt` 已包含 `gradio>=4.44`,创空间会自动安装。

## 功能特性

### 对话模式
- 自然语言输入需求
- 智能追问缺失信息
- 多轮对话优化内容
- 支持场景/平台切换

### 表单模式
- 结构化信息输入
- 快速生成软文
- 适合批量创作

### 自动核验
- 事实准确性检查(逐字比对知识库原文)
- 营销合规检查
- 图片型号匹配
- 平台规则适配

## 支持的场景与平台

### 业务场景(8种)
开学季 / 职场办公 / 内容创作 / 家庭换新 / 企业采购 / 门店到访 / 新品首发 / 节日营销

### 发布平台(4种)
- **公众号** - 800-1500字,2-4张图
- **小红书** - 300-600字,3-6张图
- **朋友圈** - 80-150字,1-3张图
- **门店海报** - 不超过80字,1张图

## 使用示例

```
用户: 给大学新生写一篇小红书

用户: MateBook 14
```

## 技术架构

```
用户输入
  ↓
需求理解 (intake.md)
  ↓
场景匹配 + 本地知识库检索 (agent/localkb.py, P1-产品参数库)
  ↓
事实摘录 (evidence.md, 逐字比对)
  ↓
图文生成 (compose.md + writer_system.md)
  ↓
事实核验 (fact_review.md) + 规则核验
  ↓
合规检查 (compliance_review.md) + 词表检查
  ↓
用户确认 / 修改意图判断 (revise_intent.md)
  ↓
按问题改写 (rewrite.md) / 重新生成 / 自动删除无依据内容
  ↓
最终输出(导出四段格式)
```

## 注意事项

1. **知识库目录**
   - 只读访问;目录里的符号链接指向目录外会被拒绝
   - 图片归属以 `图片索引.csv` 登记的型号为准,未登记或型号不符的图片会标注原因
   - 知识库目录不进 Git 仓库,部署时单独上传

2. **凭证安全**
   - 不要把 LLM Key 写入代码或截图
   - 使用创空间环境变量功能

3. **资源限制**
   - 首次启动加载提示词与知识库索引,需要几秒
   - 每次生成会多次调用 LLM,注意配额

4. **错误处理**
   - 界面会捕获并显示错误信息
   - 知识库路径无效时状态条会提示设置 `KB_LOCAL_DIR`
